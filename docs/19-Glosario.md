# WAF AI SOC v21.2 STABLE

# Glosario

## Introducción

Este glosario reúne los principales términos utilizados a lo largo de la documentación de WAF AI SOC v21.2 STABLE.

Su objetivo es proporcionar una referencia común que facilite la comprensión de los conceptos empleados en la arquitectura, los componentes y los procesos de la plataforma.

## AI Engine

Componente encargado de analizar y clasificar los eventos procesados por la plataforma antes de su almacenamiento.

## API REST

Interfaz utilizada para proporcionar acceso controlado a la información almacenada por WAF AI SOC v21.2 STABLE.

## Backup

Proceso destinado a realizar copias de seguridad de la información, configuración y recursos necesarios para la recuperación de la plataforma.

## Connector

Componente encargado de recopilar, adaptar y transferir información desde las distintas fuentes hacia el flujo interno de procesamiento de eventos.

## Dashboard Web

Interfaz gráfica utilizada para visualizar el estado del sistema y la información generada por la plataforma.

## Event Collector

Componente encargado de recibir y preparar los eventos generados por los distintos elementos del sistema.

## Event Pipeline

Flujo interno responsable del recorrido de los eventos desde su generación hasta su almacenamiento y visualización.

## Fail2Ban

Componente encargado de aplicar medidas automáticas de protección mediante acciones de bloqueo cuando se cumplen las condiciones definidas por la plataforma.

## Log

Registro de actividad generado por uno o varios componentes del sistema con fines de monitorización, diagnóstico y auditoría.

## ModSecurity

Motor de seguridad web encargado de inspeccionar el tráfico HTTP/HTTPS recibido por Nginx mediante reglas de seguridad.

## Nginx

Servidor web que actúa como punto de entrada del tráfico HTTP/HTTPS hacia WAF AI SOC v21.2 STABLE.

## OWASP Core Rule Set (CRS)

Conjunto de reglas de seguridad utilizado por ModSecurity para detectar patrones asociados a amenazas web conocidas.

## Restore

Proceso mediante el cual se recupera la información previamente almacenada mediante las copias de seguridad disponibles.

## SQLite

Sistema de base de datos utilizado por WAF AI SOC v21.2 STABLE para almacenar la información generada por la plataforma.

## Systemd

Sistema encargado de gestionar el ciclo de vida y la supervisión de los servicios que forman parte de la plataforma.

## Troubleshooting

Conjunto de procedimientos destinados al diagnóstico y resolución de incidencias del sistema.

## UFW

Firewall utilizado para controlar el tráfico de red mediante reglas de filtrado aplicadas por la plataforma.

## WAF

Web Application Firewall. Sistema diseñado para inspeccionar y proteger aplicaciones web frente a distintos tipos de amenazas.

## WAF AI SOC

Plataforma de protección web, análisis de eventos y monitorización desarrollada bajo la arquitectura WAF AI SOC v21.2 STABLE.
